GLUE:- AWS Glue is a fully managed serverless ETL (Extract, Transform, Load) service provided by AWS. It is used to discover, catalog, transform, and move data between different AWS services. AWS manages the infrastructure, scaling, availability, and execution, so developers focus only on the data processing logic.

summary :- In my hands-on, DynamoDB stored the original employee data. A Glue Crawler scanned the DynamoDB table and created metadata in the Glue Data Catalog. I created an IAM role so Glue could access DynamoDB. Then I created a Glue ETL Job that read data from the catalog, transformed or processed the data, and loaded it into S3 as Parquet files. Finally, Athena can be used to run SQL queries on the processed data stored in S3, which is more efficient for analytics on large datasets.
